Resumen HTML: Principales conceptos y etiquetas

Esta página va a resumir los principales conceptos y etiquetas vistas en Programación Web 1, en el modulo HTML

Conceptos principales de HTML

HTML

HTML (Lenguaje de Marcado de Hipertexto) es el lenguaje de marcas que se utiliza para estructurar sitios web

Elemento HTML

HTML es l aunidad básica de estructura y contenido en una página web, y esta compuesta de:

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <head>

Es una etiqueta que se utiliza para comunicarse con el navegador a traves de los meta datos, permite mejorar el SEO, además se enlazan archivos externos de estilos o scripts.

Etiqueta <body>

Dentro de esta etiqueta va todo el contenido que ve el ususario en nuestra página web.

Contenedores Semánticos

<header> Es una etiqueta utilizada para el contenido introductorio de una página web, puede contener el Logo, el menú de navegación principal, el nombre de la empresa, etc.
<nav> Etiqueta utilizada para el menú de navegación principal. Suele contener anlaces a otras páginas relacionadas o navegar por la página principal, no debe de haber más de una en la página.
<main> Es una etiqueta unica de una página web, cuyo proposito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocara el contenido principal de nuestra página.
<section> Es una etiqueta que poco a poco se intenta que sustiyuya a <div>, su uso es para dividir a una página web en secciones y agrupar contenico relacionado
<article> Es una etiqueta que se utiliza para agrupar contenido autónomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<foter> Es una etiqueta que normalmente se encuentra hasta el final de una página y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra información complementaria.
<aside> Esta etiqueta representa una sección de la página web cuyo contenido no esta directamente relacionado con el contenido principal del documento, como: barras laterales, publiciad, enlaces a otros articulos relacionados, etc.

Elemento principales de HTML

Elemento <a>

Este elemento contiene enlaces para navegar a otras páginas

  • Externos
  • Internos
  • Anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/5590900000"
Este valor envia un Whatsapp a un número especifico

href="mailto:example@gmail.com"
Este valor envia un correo a un mail especifico

Elemento <form>

Es la manera en la que los usuarios se pueden comunicar con una página web, gracias a este elemento se pueden procesar datos de los usuarios según el objetivo de nuestra página web

Por ejemplo este es un formulario tipico de inicio de sesión
